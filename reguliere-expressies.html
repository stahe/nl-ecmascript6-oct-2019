    7. Reguliere expressies

    7.1. script [regex-01]

    In de cursus PHP hadden we de volgende code gebruikt om de reguliere expressies van PHP 7 te illustreren:

    
<?php

// strikte typecontrole voor functieparameters
declare (strict_types=1);

// reguliere expressies in PHP
// de verschillende velden uit een tekenreeks ophalen
// het patroon: een reeks cijfers omgeven door willekeurige tekens
// we willen alleen de reeks cijfers ophalen
$modèle = "/(\d+)/";
// we vergelijken de tekenreeks met het patroon
compareModele2Chaine($modèle, "xyz1234abcd");
compareModele2Chaine($modèle, "12 34");
compareModele2Chaine($modèle, "abcd");

// het patroon: een reeks cijfers omgeven door willekeurige tekens
// we willen de reeks cijfers en de velden ervoor en erna
$modèle = "/^(.*?)(\d+)(.*?)$/";
// we vergelijken de tekenreeks met het patroon
compareModele2Chaine($modèle, "xyz1234abcd");
compareModele2Chaine($modèle, "12 34");
compareModele2Chaine($modèle, "abcd");

// het patroon – een datum in de notatie dd/mm/jj
$modèle = "/^\s*(\d\d)\/(\d\d)\/(\d\d)\s*$/";
compareModele2Chaine($modèle, "10/05/97");
compareModele2Chaine($modèle, "  04/04/01  ");
compareModele2Chaine($modèle, "5/1/01");

// het patroon – een decimaal getal
$modèle = "/^\s*([+|-]?)\s*(\d+\.\d*|\.\d+|\d+)\s*/";
compareModele2Chaine($modèle, "187.8");
compareModele2Chaine($modèle, "-0.6");
compareModele2Chaine($modèle, "4");
compareModele2Chaine($modèle, ".6");
compareModele2Chaine($modèle, "4.");
compareModele2Chaine($modèle, " + 4");

// einde
exit;

// --------------------------------------------------------------------------
function compareModele2Chaine(string $modèle, string $chaîne): void {
  // vergelijkt de tekenreeks $chaîne met het sjabloon $modèle
  // de tekenreeks wordt vergeleken met het patroon
  $champs = [];
  $correspond = preg_match($modèle, $chaîne, $champs);
  // weergave van de resultaten
  print "\nRésultats($modèle,$chaîne)\n";
  if ($correspond) {
    for ($i = 0; $i < count($champs); $i++) {
      print "champs[$i]=$champs[$i]\n";
    }
  } else {
    print "La chaîne [$chaîne] ne correspond pas au modèle [$modèle]\n";
  }
}

// --------------------------------------------------------------------------
function compareModèleToChaîne(modèle, chaîne) {
  // vergelijkt de tekenreeks [chaîne] met het sjabloon [modèle]
  console.log(`----------- chaîne=${chaîne}, modèle=${modèle}`)
  // de tekenreeks wordt vergeleken met het patroon
  const result1 = modèle.exec(chaîne);
  console.log(`comparaison avec exec=`, result1);
  // een andere manier om dit te doen
  const result2 = chaîne.match(modèle);
  console.log(`comparaison avec match=`, result2);
}

    Opmerkingen

    • de PHP- en JavaScript-codes lijken sterk op elkaar;
    • regel 7: merk op dat de reguliere expressie in JavaScript geen tekenreeks is, maar een object. Er worden geen aanhalingstekens of apostrofs rond de expressie geplaatst;
    • regels 41 en 44: er zijn twee methoden om hetzelfde resultaat te verkrijgen;

    De methoden [regexp.exec] en [string.match] leveren dezelfde resultaten op:

    • [null] als er geen overeenkomsten zijn tussen de tekenreeks en het sjabloon;
    • een array t, als er een overeenkomst is met:
      • t[0]: de tekenreeks die overeenkomt met het sjabloon;
      • t[1]: de tekenreeks die overeenkomt met het eerste haakje van het patroon;
      • t[2]: de tekenreeks die overeenkomt met het tweede haakje van het sjabloon;
      • …
      • t[input]: de volledige tekenreeks waarin naar het patroon is gezocht;

    7.2. script [regexp-02]

    Soms wil men geen elementen uit de geteste tekenreeks ophalen, maar alleen weten of deze overeenkomt met het patroon:

    
'use strict';

/// reguliere expressies in JavaScript
// de verschillende velden uit een tekenreeks ophalen
// het patroon: een reeks cijfers omgeven door willekeurige tekens
// we willen alleen de reeks cijfers ophalen
let modèle = /\d+/;
console.log("type d'une expression régulière : ", typeof (modèle));
// we vergelijken de tekenreeks met het patroon
compareModèleToChaîne(modèle, "xyz1234abcd");
compareModèleToChaîne(modèle, "12 34");
compareModèleToChaîne(modèle, "abcd");

// het patroon: een reeks cijfers omgeven door willekeurige tekens
// we willen de reeks cijfers en de velden ervoor en erna
modèle = /^.*?\d+.*?$/;
// we vergelijken de tekenreeks met het patroon
compareModèleToChaîne(modèle, "xyz1234abcd");
compareModèleToChaîne(modèle, "12 34");
compareModèleToChaîne(modèle, "abcd");

// het patroon: een datum in de notatie dd/mm/jj
modèle = /^\s*\d\d\/\d\d\/\d\d\s*$/;
compareModèleToChaîne(modèle, "10/05/97");
compareModèleToChaîne(modèle, "  04/04/01  ");
compareModèleToChaîne(modèle, "5/1/01");

// het patroon – een decimaal getal
modèle = /^\s*[+|-]?\s*\d+\.\d*|\.\d+|\d+\s*$/;
compareModèleToChaîne(modèle, "187.8");
compareModèleToChaîne(modèle, "-0.6");
compareModèleToChaîne(modèle, "4");
compareModèleToChaîne(modèle, ".6");
compareModèleToChaîne(modèle, "4.");
compareModèleToChaîne(modèle, " + 4");

// --------------------------------------------------------------------------
function compareModèleToChaîne(modèle, chaîne) {
  // test
  const correspond = modèle.test(chaîne);
  // vergelijkt de tekenreeks [chaîne] met het patroon [modèle]
  console.log(`----------- chaîne=${chaîne}, modèle=${modèle}, correspond=${correspond}`);
}

    Opmerkingen

    • [regexp-02] neemt de code van [regexp-01] over, met de volgende verschillen:
      • we willen geen elementen uit de geteste tekenreeks ophalen. Daarom zijn de haakjes uit de gebruikte reguliere expressies verwijderd;
      • regel 40: we gebruiken de methode [Regexp.test] om te controleren of een tekenreeks voldoet aan een reguliere expressie;
